# recruiting-copilot 分享手册（给同事）

> 一句话：一套 **AI 招聘副驾**——帮你梳理岗位要求、去 BOSS / 猎聘 / 51job 搜人、初筛、打招呼、记台账、出日报。
> 配合你手边的 AI 编程工具使用（Claude Code / Codex / WorkBuddy / 其他能读 AGENTS.md 的工具都行）。

---

## 一、它帮你干什么（30 秒看清）

| 日常动作 | 对 AI 说什么 |
|---|---|
| 第一次上手 | 「帮我初始化招聘工作区」 |
| 每天例行 | 「处理今天的招聘」（BOSS+猎聘）／「处理今天的 51job 招聘」 |
| 新开一个岗位 | 「梳理一下 XX 岗位的要求」 |
| 评估一份简历 | 把简历丢进工作区，说「评估这份简历」 |
| 不知道问谁 | 「这套工具怎么用」 |

---

## 二、前提条件（三件事）

1. **装有 Node.js（≥ 20）** 和 **Chrome 浏览器**。
2. **有 BOSS / 猎聘 / 51job 的招聘账号**（登录态存在你自己电脑的浏览器里，**各用各的账号，互不串号**）。
3. 一条能跑命令的终端（Mac 用 Terminal，Windows 用 Git Bash / PowerShell）。

---

## 三、安装（两种人群，二选一）

### 情形 1 —— 你会用终端 / 在用 AI 编程工具（推荐）

```bash
git clone https://github.com/se7enfive/recruiting-copilot.git
cd recruiting-copilot
sh skills/recruit-init/scripts/install-dependencies.sh
```

然后用你的 AI 工具打开这个目录，说：**「帮我初始化招聘工作区」**。
AI 会帮你装好三个平台的 CLI、建好工作区、逐个岗位帮你梳理招聘要求，然后每天说「处理今天的招聘」就行。

### 情形 2 —— 你不会用终端（让会的人帮你，或找负责人要打包好的 zip）

负责人会给你一个**一次性装好的分发包**：解压 → 双击安装脚本 → 用 AI 工具打开 → 说「初始化」。其余同上。

> 补一句：如果你用 Claude Code，可以额外装成插件（一条命令），获得 `/recruit-init`、`/recruit-daily`、
> `/recruit-grill` 等斜杠命令；用 DeepSeek Harness（dsh）也可以一键装成插件。两个都是可选项，不装也能用。

---

## 四、第一次初始化时会问什么

AI 会一个岗位一个岗位地跟你确认（这就是「梳理阶段」）：
- 招什么岗？**最低硬门槛**（学历 / 年限 / 地点）？
- 什么技能最重要（不能没有）？什么信号一票否决（直接排除）？
- 薪资带宽、目标公司？
答得越具体，AI 之后筛人越准。**不用一次答完，随时可改。**

---

## 五、日常怎么用（每天 5 分钟）

1. 打开你的**工作区目录**（不是仓库本身，是你初始化时生成的那个目录）。
2. 对你的 AI 说**「开始找 XX 岗位的人」**或**「今天有什么新的」**。
3. AI 会去三个平台查未读、主动搜人、按标准初筛，**把要打招呼的人列给你确认**后才发。

> ⚠️ 红线（也是保护你的）：**对外发消息、打招呼、点「不合适」默认都会先问你**，AI 绝不擅自动手。
> 这是刻意的——招聘动作不可逆，控制权一直在你手里。

---

## 六、账号安全须知（必读）

- **不要给 BOSS 开无头模式**（默认是有头的真窗口），有头模式反而是账号风控的保护壳。
  页面正常弹出窗口 = 正常工作，不是出问题。
- 登录态只存**你自己电脑的浏览器**里，别人看不到也动不了。
- 每家平台每天有查看/沟通次数配额，遇到「额度不足 / 付费弹窗」停一下，可能是当天量到了。

---

## 七、遇到问题看这里

| 现象 | 处理 |
|---|---|
| 初始化卡住 / 装不上 | 确认 Node ≥ 20、网络能访问 npm 与 GitHub |
| 首页不动 / 无反应 | 说「检查环境」让 AI 跑一遍安装脚本 |
| 想重新梳理某岗位 | 说「重新梳理 XX 岗位」 |
| 换了电脑 | 重跑一遍「安装 + 初始化」即可（历史数据在自己工作区里，拷过去继续用） |
